# Ask HealthFlow uses Client pseudonyms instead of sending identity to Claude

HealthFlow has no Business Associate Agreement with Anthropic, and the agents package redacts patient identifiers before any prompt (healthflow-agents ADR 0006). Ask HealthFlow is about specific Clients, so instead of dropping identity it replaces each Client with a stable stand-in for the conversation ("Client A, 67, ZIP 100xx") and translates stand-ins back to real Clients on the server when it shows an answer or builds an Approval. Claude never receives a Client's name or other direct identifiers, while the Broker still sees and approves "Call Inés about the pharmacy change."

We chose this over signing a BAA, which would change the policy for every agent and needs a contract and review before any real-client deployment, and over keeping Ask away from Client records, which would remove most of its value. The stand-in mapping lives only on the server for the conversation and is never part of anything sent to Claude. Moving to direct identity later under a BAA is a contained change; reversing it would not be. HealthFlow is meant for real Clients, so a BAA is expected eventually, but pseudonyms should remain the default even then: HIPAA's minimum necessary standard asks that a vendor receive only the PHI a task needs, and Ask's reasoning does not need a Client's name.

## Update, 2026-10-06: a BAA is required before Production launch

The production layer design makes a signed BAA with Anthropic a condition of letting real Client information into Production. Redaction of free text cannot be proven complete, and without a BAA a single missed identifier is a reportable breach. Pseudonyms and redaction stay as the default under the minimum necessary standard, as decided above. If the BAA is not signed in time, Production launches with the agents that read free text or Documents (Draft Appeal, Explain Coverage, Ask HealthFlow) switched off, and only the structured agents running.

The same review found that the redaction boundary allows three things HIPAA's Safe Harbor method counts as identifiers: full five-digit ZIP codes, dates more specific than a year, and ages over 89. These are closed for all agents regardless of the BAA.
